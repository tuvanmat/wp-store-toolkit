A lightweight, modular toolkit for WordPress and WooCommerce stores. Enable only the small utilities you need.

== Description ==

WP Store Toolkit collects small, single-purpose store utilities into
one plugin. Every utility is a module that can be enabled or disabled
from the toolkit settings page — under WooCommerce → Store Toolkit
when WooCommerce is active, or under Settings → Store Toolkit
otherwise; disabled modules are never loaded.

The module list is growing one module at a time — see the project
roadmap on GitHub for what is available and what is planned.

== Installation ==

1. Upload the `wp-store-toolkit` folder to `/wp-content/plugins/`.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to WooCommerce → Store Toolkit (or Settings → Store Toolkit
   if WooCommerce is not active) and enable the modules you want.
